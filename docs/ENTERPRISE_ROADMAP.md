# Enterprise / post-v1.0 roadmap (document only)

Nothing on this page is being built during the Local Edition v1.0 mission. It records decisions so they are
not lost and are not silently promised.

## Templates deferred from Local Edition v1.0

| Template | Status | Note |
|---|---|---|
| Library Management (resources/books, authors, categories, copies, members, loans, reservations) | **DEFERRED — POST-v1.0** | Does not exist. Not part of any v1.0 gallery, onboarding promise or investor claim. |
| Organization Management (departments, correspondence, tasks, projects, documents) | **DEFERRED — POST-v1.0** | Does not exist. The generic organizational-unit infrastructure is preserved; it is not a customer-facing application. |
| Generalized Inventory & Sales (Product/Supplier/Customer/Warehouse without automotive fields) | **POST-v1.0 product decision** | For v1.0 the existing Spare Parts / Inventory & Sales template is the single flagship. Build a generalized one only if pilot or customer demand shows it is needed; do not duplicate the flagship's models beforehand. |
| CRM, Procurement, Assets, Projects, Documents, Warehouses | **DEFERRED** | Reference applications from earlier phases; outside v1.0. Never offered through the built-in application catalog. |

## Other post-v1.0 candidates (not commitments)

Payroll as a real feature (the HR template's `Payroll Record` is a plain table, not a payroll engine), private
cloud and central deployment, HA, SSO / Active Directory, managed updates and fleet management, advanced
workflow and reporting, an integration marketplace, mobile applications, and any justified AI capability.
